# Radar Hostelería 1.1

PWA estática, preparada para desplegarse en GitHub Pages. No requiere compilación.

## Publicación

En **Settings → Pages**, seleccionar **Deploy from a branch**, rama `main` y carpeta `/(root)`.

La PWA incluye manifiesto, service worker, icono y una interfaz responsive. GitHub Pages sirve HTTPS, requisito para la instalación y la caché sin conexión.
